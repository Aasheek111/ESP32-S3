# ESP32-S3
Getting started with esp32-s3 guide :



-What you MUST install (Arduino IDE setup)
-ESP32 Board Support (mandatory)

If not installed, ESP32-S3 will not work.

### Steps:

1. Open Arduino IDE
2. Go to:
   File → Preferences

3. In Additional Boards Manager URLs , add:
   https://espressif.github.io/arduino-esp32/package_esp32_index.json

4. Then go:
   Tools → Board → Boards Manager

5. Search:
   ESP32
6. Install:
   esp32 by Espressif Systems

---

#Select correct board

Go to:
Tools → Board

Choose one:

* ESP32S3 Dev Module (most common)
* Or your exact ESP32-S3 board name



# Select port


Tools → Port → (your ESP32-S3)
